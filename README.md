# Hum-Raah — NGO Coordination & Civic Reporting Platform

Pakistan's coordination platform for nonprofits. Share resources. Map needs. Fund collectively.

🔗 **Live Demo:** https://humraah-frontend.vercel.app

## Tech Stack
- **Frontend:** Flutter, Dart
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **Real-time:** Socket.io
- **Auth:** JWT + AES-256 Encryption

## Features
- 🗺️ GIS Mapping with urgent flags
- 👥 Five user roles (Super Admin, NGO Admin, NGO Staff, Donor, Public User)
- 🔔 Real-time notifications via Socket.io
- 📚 Shared Knowledge Cupboard
- 🤝 Joint Tendering & Coalitions
- 📊 Automated Impact Analytics Dashboard

## Deployment
- Frontend: Vercel
- Backend: Render
- Database: MongoDB Atlas
